Own icons (F210) - your hand-made PNGs, preferred over every other icon source.

Put one file per listing at  <EXCHANGE>\<TICKER>.png  in this folder, for example
  LSE\AZN.png    JPX\9983.png    HKG\1093.png    GER\SAP.png    PAR\AIR.png    NMS\AAPL.png
EXCHANGE is the venue code Market Data stores (NMS and NYQ for Nasdaq and NYSE, LSE, JPX, HKG, GER, PAR, TOR,
AMS, MIL, EBS, STO ...); TICKER is the symbol, a ':' in it written '_'.

At most 512 x 512 pixels and 256 KB (250 x 250 recommended); 8-bit RGB, RGBA or grey, not interlaced and not
palette-based (save as 'PNG-24' / RGBA). A file outside these rules is skipped and the next source is used.
A new or replaced file shows at the next page load; no restart.
