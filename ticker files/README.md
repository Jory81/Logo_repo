# Canonical TradingView inputs

This is the unified repository's only normal input location for the dynamic
TradingView taxonomy. `config/fundamentals_tradingview_sources.json` maps the
eleven logical categories to exact filenames in this directory.

The eight corporate files and the owner-created ETF, Macro and Crypto files
belong here. Generated catalogue, mapping, Tier and round-trip export files are
outputs and must not be used as replacement source truth.

Missing inputs remain explicit missing-owner-data conditions. Do not copy an
obsolete combined legacy export or fabricate empty TXT files.
